# Study Path

**Study Path** é uma plataforma de estudos criada para organizar o aprendizado de programação e matérias acadêmicas em uma jornada progressiva, partindo do nível iniciante até conteúdos avançados.

## 📚 Conteúdo

O site possui trilhas organizadas por níveis, permitindo estudar de forma gradual

* **Cursos Comuns**

  * Matemática
  * Português
  * Física
  * Química
  * Biologia
  * História
  * Geografia

As matérias comuns são divididas em **Ensino Fundamental I, Ensino Fundamental II, Ensino Médio, Aprofundamento do Ensino Médio e nível universitário**.
